# 写作风格（本站默认）

fork 后可整篇替换为你自己的语气规范。

## 语气

- 中文为主；专有名词可保留英文
- 克制、清楚，少鸡汤，少口号
- 可有一点文学感，勿堆典故
- 技术文：链路讲清，短句 + 必要小标题
- 随笔：一段一意

## 结构

- 开篇直接入题
- 需要时再用 `##` / `###`
- 列表、表格、代码块：有用才用
- 文末少套话；有余味即可
- **不要**在正文开头重复 `description`（本站文首不展示摘要）

## description

- 一句话，约 20–40 字，说清「这篇写什么」

## 标题

- 具体，忌「一些想法」「杂记 1」

## Markdown

- 行内代码用 `` ` ``；代码块标明语言
- 链接写清用途
- mermaid：仅当图更清楚时使用

## 口吻参考

> 从这里开始。以后会写技术笔记、读后感，以及偶尔的生活记录。

> 个人博客看起来简单，实际分成三段：**写作**、**构建**、**托管**。
