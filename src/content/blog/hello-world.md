欢迎来到我的博客。

这是一个基于 **Astro** 的静态站点，托管在 **GitHub Pages** 上。文章用 Markdown 写，构建时会生成 HTML；评论通过 **Giscus**（GitHub Discussions）实现，不需要自建后端。

## 本地预览

```bash
npm install
npm run dev
```

## 写新文章

在 `src/content/blog/` 下新建 `.md` 或 `.mdx` 文件即可。
